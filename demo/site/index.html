UCM Cloud is the hosted version of Universal Crypto MCP. AI agents and people get the same 19 on-chain tools: multi-chain portfolios, gas, blocks, ENS, contract reads, token and address security scans, DeFi TVL, and swap and bridge routes that are ready to sign. You can use them from the browser console, a REST API or a single MCP URL.

Live gas across every supported network

The worker reads these directly from public RPC nodes every minute. Native prices come from DefiLlama. "Transfer" is the cost of a plain 21,000-gas transfer at the current price.

Real on-chain data, not a sandbox

Sign in with MetaMask, Rabby, Coinbase Wallet, Phantom or any EIP-6963 or Solana wallet. Every number in the console comes from a live RPC node or a public API.

◎

Portfolio & watchlist

Scan any address or ENS name on Ethereum, Base, Arbitrum, OP, Polygon, BNB Chain and Avalanche. You get native, USDC, USDT and WETH balances priced in USD. You can save up to 50 addresses to a watchlist.

⇄

Swap & bridge

Get the best route from the KyberSwap aggregator or a cross-chain route from LI.FI. Your wallet signs the approval and the swap. UCM Cloud never holds your keys or your funds.

⚠

Security scans

GoPlus checks for honeypots, buy and sell taxes, hidden owners, mint functions and holder concentration before you buy. It also screens addresses for phishing, sanctions and mixer links before you send.

⛽

Gas & explorer

See gas, base fees and block utilization across chains. Look up blocks and transactions with decoded status, read any view function by its signature, and verify signatures, including smart-account (ERC-1271) signatures.

⌁

MCP endpoint

Point Claude, Cursor or any MCP client at /mcp with an API key. All 19 tools are listed with JSON Schemas, so the agent knows exactly what each one needs.

⚿

API keys & usage

Create sk_ucm_… keys for agents and servers, and revoke them in one click. Every tool call is logged with its latency and outcome.

From wallet to signed swap in four steps

Every step is a real call. Quotes are free; swaps and bridges cost gas on the chain you choose.

Sign in

Connect a wallet and sign one message (SIWE or SIWS). You don't pay gas or create an account, and your session lasts 30 days.

See your holdings

The overview scans your address on all seven mainnets and prices every balance it finds.

Scan before you trade

Paste a token contract to run a GoPlus check for honeypots, taxes and owner privileges.

Quote and sign

Pick a pair, check the route, price impact and minimum out, then approve and swap from your own wallet.

Built for agents first

The console calls the same routes your agents do. Create a key under API keys and call these routes:

  • GET /api/tools lists every tool with its JSON Schema
  • POST /api/run/:tool runs one tool with a JSON body
  • GET /api/live returns the public gas board shown above
  • POST /mcp is a stateless MCP endpoint over Streamable HTTP (JSON-RPC, batches allowed)
# Scan a portfolio across 7 chains
curl -s -X POST https://universal-crypto-mcp.ninabrekkerese.workers.dev/api/run/get_portfolio \
  -H "authorization: Bearer $UCM_KEY" \
  -H "content-type: application/json" \
  -d '{"address":"vitalik.eth"}'

# mcp.json
{
  "mcpServers": {
    "ucm": {
      "type": "http",
      "url": "https://universal-crypto-mcp.ninabrekkerese.workers.dev/mcp",
      "headers": { "Authorization": "Bearer sk_ucm_…" }
    }
  }
}
