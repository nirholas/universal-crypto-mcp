## Core API

### Chain Operations

| Tool | Description |
|------|-------------|
| `get_block` | Get block by number or hash |
| `get_transaction` | Get transaction details |
| `get_transaction_receipt` | Get transaction receipt |
| `estimate_gas` | Estimate gas for transaction |
| `get_gas_price` | Get current gas prices |
| `get_chain_id` | Get chain ID |
| `get_block_number` | Get latest block number |

### Wallet Operations

| Tool | Description |
|------|-------------|
| `get_balance` | Get native token balance |
| `get_token_balance` | Get ERC20 token balance |
| `get_all_balances` | Get all token balances |
| `transfer` | Transfer native tokens |
| `transfer_token` | Transfer ERC20 tokens |
| `sign_message` | Sign a message |
| `verify_signature` | Verify a signature |

### Contract Operations

| Tool | Description |
|------|-------------|
| `read_contract` | Read from contract |
| `write_contract` | Write to contract |
| `deploy_contract` | Deploy a contract |
| `get_contract_abi` | Get contract ABI |
| `verify_contract` | Verify contract source |
| `get_events` | Get contract events |

## DeFi API

### Swaps

```typescript
// Swap tokens using Uniswap V3
const result = await mcp.call('swap_tokens', {
  fromToken: 'ETH',
  toToken: 'USDC',
  amount: '1.0',
  slippage: 0.5,
  chain: 'ethereum'
});
```

| Tool | Description |
|------|-------------|
| `swap_tokens` | Execute a token swap |
| `get_swap_quote` | Get swap price quote |
| `get_swap_route` | Get optimal swap route |
| `approve_token` | Approve token spending |

## Error Handling

All API calls return a consistent response format:

```typescript
// Success response
{
  success: true,
  data: { /* result data */ },
  metadata: {
    chain: 'ethereum',
    blockNumber: 12345678,
    timestamp: 1706745600
  }
}

// Error response
{
  success: false,
  error: {
    code: 'INSUFFICIENT_BALANCE',
    message: 'Insufficient balance for transaction',
    details: { /* additional info */ }
  }
}
```

### Common Error Codes

| Code | Description |
|------|-------------|
| `INSUFFICIENT_BALANCE` | Not enough balance |
| `INVALID_ADDRESS` | Invalid wallet address |
| `SLIPPAGE_EXCEEDED` | Slippage tolerance exceeded |
| `RATE_LIMITED` | API rate limit reached |
| `NETWORK_ERROR` | Network connection error |
| `UNAUTHORIZED` | Missing or invalid API key |
