## Chain Configuration

### Default RPC URLs

Each chain has a default public RPC, but for production use we recommend:

- [Alchemy](https://alchemy.com) - Best for EVM chains
- [QuickNode](https://quicknode.com) - Multi-chain support
- [Infura](https://infura.io) - Ethereum-focused
- [Helius](https://helius.dev) - Best for Solana

### Adding Custom RPC

Configure custom RPC URLs in your environment:

```bash
# .env
ETHEREUM_RPC_URL=https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY
BASE_RPC_URL=https://base-mainnet.g.alchemy.com/v2/YOUR_KEY
ARBITRUM_RPC_URL=https://arb-mainnet.g.alchemy.com/v2/YOUR_KEY
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=YOUR_KEY
```

Or in `config.json`:

```json
{
  "chains": {
    "ethereum": {
      "rpcUrl": "https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY",
      "chainId": 1,
      "enabled": true
    }
  }
}
```

## Bridge Support

Cross-chain bridging supported via:

- **Hop Protocol** - L2 ↔ L2
- **Across Protocol** - Fast L2 bridges
- **Stargate** - LayerZero bridges
- **Wormhole** - Multi-chain

```typescript
// Get bridge quote
const quote = await mcp.call('get_bridge_quote', {
  fromChain: 'ethereum',
  toChain: 'base',
  token: 'USDC',
  amount: '1000'
});
```
