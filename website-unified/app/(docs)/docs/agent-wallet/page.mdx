# Agent Wallet

Agent Wallets are specialized wallets designed for AI agents, with built-in spending controls, service allowlists, and automatic top-up functionality.

## Why Agent Wallets?

AI agents need to make payments autonomously but require:

- **Budget Controls**: Daily, monthly, and per-transaction limits
- **Service Restrictions**: Allowlists/blocklists for approved services
- **Owner Oversight**: Human control and monitoring
- **Automatic Refills**: Top-up when balance runs low
- **Audit Trail**: Complete activity history

## Key Features

### 🔒 Spending Policies

Set granular limits on agent spending:

```typescript
const spendingPolicy = {
  dailyLimit: "10.00",         // Max $10/day
  perTransactionLimit: "1.00",  // Max $1 per payment
  monthlyLimit: "100.00",       // Max $100/month
  cooldownSeconds: 60           // Min 60s between payments
}
```

### ✅ Service Allowlists

Control which services the agent can pay:

```typescript
const allowlist = {
  mode: "allowlist",
  services: [
    "openai-*",        // All OpenAI services
    "anthropic-*",     // All Anthropic services
    "coingecko-api",   // Specific service
    "specific-api-id"
  ]
}
```

### 🔄 Auto Top-Up

Automatically refill the wallet when balance is low:

```typescript
const autoTopUp = {
  enabled: true,
  threshold: "10.00",    // Top up when below $10
  amount: "50.00",       // Add $50
  source: "credits",     // From credit balance
  maxPerMonth: "200.00"  // Safety cap
}
```

## Quick Start

### Owner Side: Create Wallet

```typescript
import { WalletManager } from '@nirholas/agent-wallet';

const manager = new WalletManager();

const { wallet, apiKey } = await manager.createWallet({
  name: 'Research Agent',
  owner: 'user_123',
  network: 'base',
  initialBalance: '50.00',
  spendingPolicy: {
    dailyLimit: '10.00',
    perTransactionLimit: '1.00',
    monthlyLimit: '100.00',
  },
  allowlist: {
    mode: 'allowlist',
    services: ['approved-api-*'],
  },
  autoTopUp: {
    enabled: true,
    threshold: '10.00',
    amount: '50.00',
    source: 'credits',
    maxPerMonth: '200.00',
  },
});

// Save these securely
console.log(`Wallet ID: ${wallet.id}`);
console.log(`API Key: ${apiKey}`);
```

### Agent Side: Use Wallet

```typescript
import { AgentWalletClient } from '@nirholas/agent-wallet';
import axios from 'axios';

const client = new AgentWalletClient({
  walletId: process.env.AGENT_WALLET_ID,
  apiKey: process.env.AGENT_WALLET_API_KEY,
  facilitatorUrl: 'https://facilitator.x402.org',
});

// Check budget
const budget = await client.getBudget();
console.log(`Daily remaining: $${budget.dailyRemaining}`);

// Wrap HTTP client for automatic payments
const api = client.wrapAxios(axios.create({
  baseURL: 'https://api.example.com'
}));

// Automatic payment on HTTP 402
const data = await api.get('/paid-endpoint');
```

## API Reference

### WalletManager

```typescript
class WalletManager {
  // Create a new agent wallet
  createWallet(options: CreateWalletOptions): Promise<{ wallet: Wallet; apiKey: string }>
  
  // Get wallet by ID
  getWallet(walletId: string): Promise<Wallet>
  
  // Update wallet settings
  updateWallet(walletId: string, updates: WalletUpdates): Promise<Wallet>
  
  // Fund wallet
  fundWallet(walletId: string, amount: string): Promise<Transaction>
  
  // Withdraw from wallet
  withdraw(walletId: string, amount: string, to: string): Promise<Transaction>
  
  // Get wallet activity
  getActivity(walletId: string, options?: ActivityOptions): Promise<Activity[]>
  
  // Rotate API key
  rotateApiKey(walletId: string): Promise<string>
}
```

### AgentWalletClient

```typescript
class AgentWalletClient {
  // Get remaining budget
  getBudget(): Promise<Budget>
  
  // Make a payment
  pay(serviceId: string, amount: string): Promise<PaymentResult>
  
  // Wrap axios for automatic payments
  wrapAxios(instance: AxiosInstance): AxiosInstance
  
  // Get payment history
  getHistory(options?: HistoryOptions): Promise<Payment[]>
}
```

## Security Considerations

- **Never share API keys** - Treat them like passwords
- **Use allowlists** - Explicitly define approved services
- **Set reasonable limits** - Start low and increase as needed
- **Monitor activity** - Review logs regularly
- **Rotate keys** - Rotate API keys periodically
