## Quick Start

Get up and running in under 5 minutes:

```bash
# Install the package
npm install @nirholas/universal-crypto-mcp

# Or use directly with npx
npx @nirholas/universal-crypto-mcp
```

Configure Claude Desktop:

```json
{
  "mcpServers": {
    "crypto": {
      "command": "npx",
      "args": ["@nirholas/universal-crypto-mcp"]
    }
  }
}
```

Then ask Claude: *"What's the price of ETH?"* or *"Check my wallet balance on Base"*

## Featured Capabilities

### 🔧 380+ Crypto Tools

- **DeFi**: Swaps, lending, staking, yield farming
- **Trading**: CEX integration, order management
- **Wallets**: Multi-chain balance tracking
- **NFTs**: Marketplace integration
- **Security**: Contract analysis, rug detection

### 💳 x402 Payment Rails

- HTTP 402 Payment Required protocol
- Multi-chain support (20+ networks)
- Micropayments from $0.001
- AI agent autonomous payments

### 🏪 Service Marketplace

- Discover paid AI services
- Register your own APIs
- Subscription management
- Reputation system
