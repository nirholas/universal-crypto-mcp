## Quick Examples

### Get Token Price

```typescript
// Ask Claude: "What's the current price of ETH?"

const price = await mcp.call('get_price', {
  symbol: 'ETH',
  currency: 'USD'
});

console.log(`ETH: $${price.usd}`);
```

### Swap Tokens

```typescript
// Ask Claude: "Swap 0.1 ETH for USDC on Base"

const swap = await mcp.call('swap_tokens', {
  fromToken: 'ETH',
  toToken: 'USDC',
  amount: '0.1',
  chain: 'base'
});

console.log(`Swapped for ${swap.amountOut} USDC`);
```

### Check Security

```typescript
// Ask Claude: "Is this token safe? 0x..."

const analysis = await mcp.call('analyze_token', {
  address: '0x...',
  chain: 'ethereum'
});

console.log(`Risk score: ${analysis.riskScore}/100`);
```
