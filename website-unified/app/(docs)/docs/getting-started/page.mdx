# Getting Started

Welcome to **Universal Crypto MCP** - the largest Model Context Protocol (MCP) server for cryptocurrency tools, providing 380+ tools for DeFi, NFTs, payments, and more.

## What is Universal Crypto MCP?

Universal Crypto MCP is a comprehensive toolkit that enables AI agents (like Claude, GPT, and Cursor) to interact with blockchain networks, manage crypto payments, and access decentralized services - all through a standardized protocol.

## Quick Start

Get started with Universal Crypto MCP in under 5 minutes:

```bash
# Install via npm
npm install @nirholas/universal-crypto-mcp

# Or use directly with npx
npx @nirholas/universal-crypto-mcp
```

### Add to Claude Desktop

Configure Claude Desktop to use Universal Crypto MCP:

```json
{
  "mcpServers": {
    "universal-crypto": {
      "command": "npx",
      "args": ["@nirholas/universal-crypto-mcp"],
      "env": {
        "ETHEREUM_RPC_URL": "https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY"
      }
    }
  }
}
```

See the [Installation Guide](/docs/getting-started/installation) for detailed instructions.
