# x402 Payment Protocol

**AI agents can now pay for things on the internet!** 💸

The x402 protocol enables AI agents to automatically pay for premium APIs, services, and data using cryptocurrency. It's HTTP 402 "Payment Required" - but actually implemented.

## What is x402?

x402 is a protocol that allows:
- 🤖 **AI agents** to automatically pay for API calls
- 💰 **API providers** to monetize their services with pay-per-use pricing
- ⚡ **Instant micropayments** using EVM and Solana
- 🔄 **Agent-to-agent commerce** - AI agents selling to other AI agents

### Example Flow

```typescript
// AI agent (Claude) wants premium weather data
User: "Get premium weather forecast for Tokyo"

Claude: 🔍 Checking x402 balance... $45.23 USDC on Arbitrum
        💳 Paying $0.01 for premium API access...
        ✅ Payment confirmed! Transaction: 0x1234...
        
        🌤️ Tokyo Weather (7-day premium forecast):
        - Monday: 75°F, Sunny, 0% rain
        - Tuesday: 72°F, Partly cloudy...
```

The agent automatically:
1. Detected the API requires payment (402 response)
2. Checked wallet balance
3. Paid the required amount
4. Retried the request with payment proof
5. Got the premium data

## Why x402?

### Traditional APIs
- ❌ Require manual sign-up
- ❌ Monthly subscriptions (pay even if not used)
- ❌ Complex API key management
- ❌ No agent-to-agent payments

### x402 Protocol
- ✅ Pay-per-use (only pay for what you use)
- ✅ No sign-up or API keys needed
- ✅ Automatic payment by AI agents
- ✅ Agent-to-agent commerce enabled
- ✅ Instant settlement
- ✅ Multi-chain support (EVM + Solana)

## Quick Start

### For API Providers (Servers)

Make your API x402-enabled in 3 lines:

```typescript
import { x402Middleware } from '@nirholas/x402'

// Add x402 middleware to your Express/Hono/Next.js API
app.use(x402Middleware({
  price: '0.01', // $0.01 per request
  chain: 'arbitrum',
  token: 'USDC'
}))
```

Now your API automatically:
- Returns 402 for unpaid requests
- Accepts crypto payments
- Verifies payments on-chain
- Grants access after payment

### For AI Agents (Clients)

Enable your agent to pay for APIs:

```typescript
import { x402Client } from '@nirholas/x402'

// Wrap your HTTP client with x402
const client = x402Client({
  wallet: process.env.AGENT_WALLET_KEY,
  autoPayment: true, // Automatically pay for 402 responses
  maxPrice: '1.00', // Don't spend more than $1 per request
})

// Agent automatically pays if API requires payment
const data = await client.get('https://premium-api.com/data')
```

## Key Concepts

### 1. Payment Required (402 Response)

When an API requires payment, it returns HTTP 402 with payment details:

```json
{
  "error": "Payment Required",
  "payment": {
    "chain": "arbitrum",
    "token": "USDC",
    "amount": "0.01",
    "recipient": "0x1234...",
    "nonce": "abc123"
  }
}
```

### 2. Payment Mechanisms

x402 supports multiple payment mechanisms:

- **EVM Mechanism**: USDC/USDT on Ethereum, Arbitrum, Optimism, Base, Polygon
- **SVM Mechanism**: USDC on Solana
- **Custom Mechanisms**: Build your own payment logic

### 3. Lifecycle Hooks

Customize payment behavior with hooks:

```typescript
const server = x402Server({
  hooks: {
    beforePayment: async (req) => {
      // Custom validation before accepting payment
    },
    afterPayment: async (req, payment) => {
      // Track revenue, update database, etc.
    },
    onError: async (req, error) => {
      // Handle payment errors
    }
  }
})
```

### 4. Facilitator

The facilitator manages payment infrastructure:
- Monitors payment channels
- Routes payments efficiently
- Handles multi-chain complexity
- Provides analytics

x402 works on multiple blockchains:

**EVM Chains**:
- Ethereum (mainnet, Sepolia)
- Arbitrum
- Optimism
- Base
- Polygon
- BNB Chain

**Non-EVM**:
- Solana

- Arbitrum: ~$0.01 gas, 2-second finality
- Solana: ~$0.0001 gas, <1-second finality

## Integration Examples

### Express Server
```typescript
import express from 'express'
import { x402Express } from '@nirholas/x402'

const app = express()
app.use(x402Express({ price: '0.01', chain: 'arbitrum' }))

app.get('/premium-data', (req, res) => {
  res.json({ data: 'This cost $0.01 to access!' })
})
```

### Next.js API Route
```typescript
import { x402Next } from '@nirholas/x402'

export default x402Next(
  async (req, res) => {
    res.json({ premium: 'content' })
  },
  { price: '0.05', chain: 'base' }
)
```

### Python FastAPI
```python
from fastapi import FastAPI
from x402 import x402_middleware

app = FastAPI()
app.add_middleware(x402_middleware(price="0.01", chain="arbitrum"))

@app.get("/premium")
async def premium_data():
    return {"data": "Paid content"}
```
