# Agenti MCP Server

AI agent framework for the Universal Crypto MCP ecosystem.

## Installation

```bash
pnpm add @universal-crypto-mcp/agent-agenti
```

## Usage

```typescript
import { createAgent } from '@universal-crypto-mcp/agent-agenti';

const agent = createAgent({
  name: 'MyAgent',
  description: 'A custom AI agent'
});
```
