# Polkadot MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Polkadot relay chain and parachains explorer.

## Tools

| Tool | Description |
|------|-------------|
| `polkadot_account` | Get account balance |
| `polkadot_parachains` | Get parachains |
| `polkadot_stats` | Get network stats |
| `polkadot_validators` | Get validators |
| `polkadot_crowdloans` | Get crowdloans |
