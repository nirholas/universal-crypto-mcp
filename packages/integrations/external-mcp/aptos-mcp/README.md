# Aptos MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Aptos blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `aptos_account` | Get account info |
| `aptos_transactions` | Get transactions |
| `aptos_stats` | Get network stats |
| `aptos_nfts` | Get NFTs |
| `aptos_validators` | Get validators |
