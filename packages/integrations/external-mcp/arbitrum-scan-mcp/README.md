# Arbitrum Scan MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Arbitrum L2 blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `arbitrum_transactions` | Get transaction history |
| `arbitrum_balance` | Get ETH balance |
| `arbitrum_tokens` | Get token balances |
| `arbitrum_gas` | Get gas prices |
| `arbitrum_l2_stats` | Get L2 statistics |
| `arbitrum_bridge` | Get bridge transactions |
