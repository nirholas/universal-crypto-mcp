# PolygonScan MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Polygon blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `polygon_transactions` | Get transaction history |
| `polygon_balance` | Get MATIC balance |
| `polygon_tokens` | Get token balances |
| `polygon_gas` | Get gas prices |
| `polygon_stats` | Get network stats |
| `polygon_validators` | Get PoS validators |
