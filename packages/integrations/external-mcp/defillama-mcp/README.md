# DeFiLlama MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

DeFi TVL, protocol data, and analytics from DeFiLlama.

## Features

- 📊 **Protocol TVL** - Track TVL across 1000+ protocols
- ⛓️ **Chain Analytics** - Compare TVL across chains
- 💰 **Yield Data** - Best APY opportunities
- 💵 **Stablecoins** - Market cap and dominance
- 📈 **Historical Data** - TVL trends over time

## Tools

| Tool | Description |
|------|-------------|
| `defillama_protocols` | Get top protocols by TVL |
| `defillama_chains` | Get chain TVL comparison |
| `defillama_yields` | Get top yield opportunities |
| `defillama_stablecoins` | Get stablecoin data |
| `defillama_protocol` | Get detailed protocol info |

## Usage

```typescript
import { registerDeFiLlama } from '@nirholas/defillama-mcp';

registerDeFiLlama(server);
```

## Example Prompts

- "What are the top 10 DeFi protocols by TVL?"
- "Compare TVL across Ethereum, Solana, and Arbitrum"
- "Find the best yield opportunities on Ethereum"
