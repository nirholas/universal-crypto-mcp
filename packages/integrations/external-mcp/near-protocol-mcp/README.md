# NEAR Protocol MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

NEAR Protocol blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `near_account` | Get account info |
| `near_staking_pools` | Get staking pools |
| `near_stats` | Get network stats |
| `near_transactions` | Get transactions |
| `near_ft_balance` | Get FT balance |
