# Cardano MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Cardano blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `cardano_account` | Get account/staking info |
| `cardano_stake_pools` | Get stake pools |
| `cardano_stats` | Get network stats |
| `cardano_transactions` | Get transactions |
| `cardano_native_tokens` | Get native tokens |
