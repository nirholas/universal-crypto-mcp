# CoinGecko Enhanced MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Enhanced CoinGecko integration with advanced features.

## Features

- 💰 **Price Data** - Multi-currency price tracking
- 📊 **Market Overview** - Total market cap, BTC dominance
- 🔥 **Trending** - Hot coins and momentum
- 📁 **Categories** - DeFi, NFT, Gaming, AI sectors
- 📈 **OHLC Charts** - Historical price data

## Tools

| Tool | Description |
|------|-------------|
| `coingecko_price` | Get coin price and market data |
| `coingecko_market` | Get market overview |
| `coingecko_trending` | Get trending coins |
| `coingecko_categories` | Get category data |
| `coingecko_search` | Search for coins |
| `coingecko_ohlc` | Get OHLC chart data |
