# Etherscan Advanced MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Advanced Ethereum blockchain explorer.

## Features

- 📜 **Transactions** - Full transaction history
- 📄 **Contracts** - Verification and ABI
- 🪙 **Token Transfers** - ERC20/721 transfers
- ⛽ **Gas Tracker** - Real-time gas prices
- 🔍 **Internal Txs** - Internal call traces

## Tools

| Tool | Description |
|------|-------------|
| `etherscan_transactions` | Get transaction history |
| `etherscan_contract` | Get contract info/ABI |
| `etherscan_token_transfers` | Get token transfers |
| `etherscan_gas` | Get gas prices |
| `etherscan_internal_tx` | Get internal transactions |
