# Base Scan MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Base L2 (Coinbase) blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `base_transactions` | Get transaction history |
| `base_balance` | Get ETH balance |
| `base_tokens` | Get token balances |
| `base_gas` | Get gas prices |
| `base_stats` | Get network stats |
| `base_nfts` | Get Base NFTs |
