# Dune Analytics MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

SQL analytics and blockchain dashboards from Dune.

## Features

- 📊 **SQL Queries** - Execute Dune queries
- 💱 **DEX Volume** - Track swap volumes
- 🎨 **NFT Analytics** - Market and collection data
- 👛 **Wallet Analysis** - On-chain history
- 📈 **Dashboards** - Popular analytics dashboards

## Tools

| Tool | Description |
|------|-------------|
| `dune_query` | Execute a Dune query |
| `dune_dex_volume` | Get DEX volume analytics |
| `dune_nft_analytics` | Get NFT market data |
| `dune_wallet` | Get wallet analytics |
| `dune_dashboards` | Get popular dashboards |
