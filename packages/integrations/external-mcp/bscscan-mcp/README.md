# BscScan MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

BNB Smart Chain blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `bsc_transactions` | Get transaction history |
| `bsc_balance` | Get BNB balance |
| `bsc_tokens` | Get token balances |
| `bsc_gas` | Get gas prices |
| `bsc_stats` | Get network stats |
| `bsc_bep20` | Get BEP-20 tokens |
