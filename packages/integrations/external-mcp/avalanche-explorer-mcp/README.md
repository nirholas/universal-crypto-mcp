# Avalanche Explorer MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Avalanche C-Chain blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `avalanche_transactions` | Get transaction history |
| `avalanche_balance` | Get AVAX balance |
| `avalanche_tokens` | Get token balances |
| `avalanche_gas` | Get gas prices |
| `avalanche_stats` | Get network stats |
| `avalanche_subnets` | Get subnets |
| `avalanche_staking` | Get staking info |
