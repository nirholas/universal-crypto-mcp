# Arkham Intelligence MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

On-chain intelligence and entity tracking.

## Features

- 🔍 **Entity Identification** - Identify wallets by address
- 📊 **Exchange Flows** - Track exchange deposits/withdrawals
- 🏷️ **Address Labels** - Label unknown addresses
- 🔗 **Transaction Graph** - Entity transaction history
- 🏛️ **Government Tracking** - Seizure address monitoring

## Tools

| Tool | Description |
|------|-------------|
| `arkham_identify` | Identify entity by address |
| `arkham_transactions` | Get entity transactions |
| `arkham_exchange_flows` | Get exchange flow data |
| `arkham_search` | Search for entities |
| `arkham_labels` | Get address labels |
| `arkham_government` | Get government addresses |
