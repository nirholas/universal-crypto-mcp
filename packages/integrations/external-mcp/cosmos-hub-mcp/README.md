# Cosmos Hub MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Cosmos Hub and IBC ecosystem explorer.

## Tools

| Tool | Description |
|------|-------------|
| `cosmos_account` | Get account balance/delegations |
| `cosmos_validators` | Get validators |
| `cosmos_ibc_channels` | Get IBC channels |
| `cosmos_stats` | Get network stats |
| `cosmos_proposals` | Get governance proposals |
