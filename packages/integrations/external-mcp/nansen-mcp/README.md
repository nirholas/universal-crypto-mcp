# Nansen MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Smart money tracking and wallet analytics.

## Features

- 🧠 **Smart Money** - Track fund and whale wallets
- 💰 **Token Flow** - Inflow/outflow analysis
- 🐋 **Whale Alerts** - Large transaction monitoring
- 👛 **Wallet Profiles** - Deep wallet analytics
- 🔥 **Hot Tokens** - Smart money accumulation signals

## Tools

| Tool | Description |
|------|-------------|
| `nansen_smart_money` | Get smart money holders |
| `nansen_token_flow` | Get token flow analysis |
| `nansen_whale_alerts` | Get whale alerts |
| `nansen_wallet` | Get wallet profile |
| `nansen_hot_tokens` | Get hot token signals |
