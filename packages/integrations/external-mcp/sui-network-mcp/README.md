# Sui Network MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Sui Network blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `sui_account` | Get account info |
| `sui_objects` | Get owned objects |
| `sui_stats` | Get network stats |
| `sui_transaction` | Get transaction details |
| `sui_validators` | Get validators |
