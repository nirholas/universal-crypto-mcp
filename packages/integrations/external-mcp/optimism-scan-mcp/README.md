# Optimism Scan MCP

> **Part of [Universal Crypto MCP](https://github.com/nirholas/universal-crypto-mcp)**  
> By [nich](https://x.com/nichxbt)

Optimism L2 blockchain explorer.

## Tools

| Tool | Description |
|------|-------------|
| `optimism_transactions` | Get transaction history |
| `optimism_balance` | Get ETH balance |
| `optimism_tokens` | Get token balances |
| `optimism_gas` | Get gas prices |
| `optimism_stats` | Get network stats |
| `optimism_rewards` | Get OP rewards |
