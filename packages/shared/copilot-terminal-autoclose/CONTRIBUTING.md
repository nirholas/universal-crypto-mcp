# Contributing to Copilot Terminal Auto-Close

Thank you for your interest in contributing! This project is intentionally minimal, but there are still ways to help.

## Ways to Contribute

### 📝 Documentation
- Improve README clarity
- Add examples for different use cases
- Translate documentation
- Fix typos

### 🐛 Bug Reports
- Report issues with the setting
- Document edge cases
- Test with different VS Code versions

### 💡 Feature Requests
- Suggest related settings
- Propose integration ideas
- Share workflow improvements

## Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Commit with clear messages: `git commit -m "Add feature X"`
5. Push to your fork: `git push origin feature/your-feature`
6. Open a Pull Request

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Focus on the issue, not the person

## Questions?

Open an issue with the `question` label.
