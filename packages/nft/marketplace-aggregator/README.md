# Blur MCP Server

> Pro NFT trading integration for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 💰 **Bidding** - Collection, trait, and token bids
- 📊 **Floor Depth** - Real-time depth analysis
- 🪙 **BLUR Token** - Token info and staking
- 📈 **Analytics** - Pro trading features

## Available Tools

- `blur_get_collection_bids` - Collection bid data
- `blur_get_floor_depth` - Floor price depth
- `blur_get_token_info` - BLUR token info
- `blur_get_marketplace_stats` - Marketplace stats
