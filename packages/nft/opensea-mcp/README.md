# OpenSea MCP Server

> NFT marketplace integration for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 🖼️ **Collections** - Get collection info and stats
- 📊 **Rankings** - Top collections by volume
- 🔍 **NFT Data** - Individual NFT details
- 🏪 **Seaport** - Trading protocol information

## Available Tools

- `opensea_get_collection` - Collection details
- `opensea_get_top_collections` - Top collections
- `opensea_get_nft` - Specific NFT data
- `opensea_get_seaport_info` - Seaport protocol info

## API Key

For production use, set `OPENSEA_API_KEY` environment variable.
