> Gaming NFT integration for AI assistants

**Author:** nirholas (Nich)

## Features

- 🎮 **Axie Stats** - Classes, parts, genetics
- 🏪 **Marketplace** - Listings and filters
- 🧬 **Breeding** - Mechanics and costs
- ⛓️ **Ronin** - Blockchain ecosystem

## Available Tools

- `axie_get_axie_info` - Specific Axie data
- `axie_get_marketplace` - Marketplace listings
- `axie_get_breeding_info` - Breeding mechanics
- `axie_get_ronin_info` - Ronin blockchain info
