## Servers

| Server | Description |
|--------|-------------|
| `@nirholas/opensea-mcp` | NFT marketplace - collections, floor prices, listings |
| `@nirholas/blur-mcp` | Pro NFT trading - bidding, sweeping, analytics |
| `@nirholas/axie-infinity-mcp` | Gaming NFTs - Axies, breeding, Ronin blockchain |

## Installation

```bash
npm install @nirholas/opensea-mcp @nirholas/blur-mcp @nirholas/axie-infinity-mcp
```
