# Safe (Gnosis) MCP Server

> Multi-sig wallet management for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 🔐 **Safe Info** - Owners, threshold, nonce
- ⏳ **Pending Txs** - Awaiting signatures
- 📜 **History** - Executed transactions
- 💰 **Balances** - Token holdings

## Supported Chains

- Ethereum Mainnet (1)
- Polygon (137)
- Arbitrum (42161)
- Optimism (10)
- Base (8453)

## Available Tools

- `safe_get_info` - Get Safe details
- `safe_get_pending_transactions` - Pending txs
- `safe_get_history` - Transaction history
- `safe_get_balances` - Token balances
