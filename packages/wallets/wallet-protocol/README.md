# WalletConnect MCP Server

> Wallet connectivity for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 📱 **Wallet Discovery** - List supported wallets
- 🔗 **Sessions** - Create connections
- 📊 **Status** - Monitor connections
- 🚫 **Disconnect** - Clean session cleanup

## Available Tools

- `walletconnect_list_wallets` - List supported wallets
- `walletconnect_create_session` - Create new session
- `walletconnect_get_session` - Get session status
- `walletconnect_disconnect` - Disconnect session

## Environment

- `WALLETCONNECT_PROJECT_ID` - From cloud.walletconnect.com
