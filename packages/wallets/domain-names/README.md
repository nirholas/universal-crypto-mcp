# ENS Domains MCP Server

> Ethereum Name Service integration for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 🔗 **Name Resolution** - ENS to address
- 🔄 **Reverse Lookup** - Address to ENS
- 🖼️ **Avatars** - Profile pictures
- 📝 **Text Records** - Social links, email, etc.

## Available Tools

- `ens_resolve_name` - Resolve ENS to address
- `ens_reverse_lookup` - Address to ENS name
- `ens_get_avatar` - Get avatar URL
- `ens_get_text_records` - Get profile data

## Environment

- `ETH_RPC_URL` - Ethereum RPC endpoint
