# @nirholas/agenti

This package is the earlier name of
[@nirholas/universal-crypto-mcp](https://www.npmjs.com/package/@nirholas/universal-crypto-mcp).

Since 0.1.1 it is a thin delegation layer: installing it installs the
maintained server, the `agenti` and `x402` binaries keep working, and the
library import re-exports the same API. Security fixes land in
universal-crypto-mcp and reach both names automatically.

If you are starting fresh, depend on `@nirholas/universal-crypto-mcp`
directly.
