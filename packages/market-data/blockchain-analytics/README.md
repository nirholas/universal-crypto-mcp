# Dune Analytics MCP Server

> On-chain analytics integration for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 📊 **Query Execution** - Run SQL queries on blockchain data
- 📈 **Results** - Retrieve query results
- 🔥 **Popular Queries** - Discover community queries
- 🌐 **Multi-Chain** - Ethereum, L2s, Solana, and more

## Available Tools

- `dune_execute_query` - Execute a query by ID
- `dune_get_results` - Get execution results
- `dune_get_popular_queries` - Popular queries by category
- `dune_get_api_info` - API capabilities info

## API Key

Set `DUNE_API_KEY` environment variable. Get key from https://dune.com/settings/api
