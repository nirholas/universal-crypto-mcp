# CoinGecko Pro MCP Server

> Market data integration for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 💰 **Prices** - Real-time cryptocurrency prices
- 🏆 **Rankings** - Top coins by market cap
- 🔥 **Trending** - Popular coins
- 📊 **Details** - Comprehensive coin data

## Available Tools

- `coingecko_get_price` - Get current prices
- `coingecko_get_top_coins` - Top coins by market cap
- `coingecko_get_trending` - Trending coins
- `coingecko_get_coin_details` - Detailed coin info

## API Key (Optional)

For higher rate limits, set `COINGECKO_API_KEY` for Pro API access.
