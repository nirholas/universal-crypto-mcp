# DeFiLlama MCP Server

> TVL aggregator integration for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 📊 **Protocol TVL** - Get TVL for any protocol
- 🏆 **Rankings** - Top protocols by TVL
- ⛓️ **Chain Data** - TVL by blockchain
- 💰 **Yields** - Top yield opportunities

## Available Tools

- `defillama_get_protocol` - Protocol TVL and data
- `defillama_get_top_protocols` - Top protocols by TVL
- `defillama_get_chain_tvl` - Chain TVL stats
- `defillama_get_yields` - Top yield pools

## No API Key Required

DeFiLlama API is free and public.
