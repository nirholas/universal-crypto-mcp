# Yearn Finance MCP Server

> Yield aggregation integration for AI assistants via the Model Context Protocol

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**GitHub:** [github.com/nirholas](https://github.com/nirholas)  
**License:** MIT

## Features

- 🏦 **Vault Info** - TVL, price per share, underlying assets
- 📈 **APY Tracking** - Current yield and historical performance
- 👤 **Positions** - User deposits and earnings
- 🎯 **Strategies** - Active vault strategies

## Installation

```bash
npm install @nirholas/yearn-mcp
```

## Available Tools

- `yearn_get_vault_info` - Get vault details
- `yearn_get_top_vaults` - List top vaults by TVL
- `yearn_get_user_position` - Get user's vault position
- `yearn_get_vault_strategies` - Get vault strategies
