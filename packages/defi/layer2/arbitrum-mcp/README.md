# Arbitrum MCP Server

> Layer 2 integration for AI assistants via the Model Context Protocol

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)

**License:** MIT

## Features

- 🔷 **Network Status** - Block height, gas prices, chain status
- 🌉 **Bridging** - Deposit/withdrawal estimation
- ⛽ **Gas Comparison** - L1 vs L2 cost savings
- 📱 **dApps** - Popular protocols on Arbitrum

## Installation

```bash
npm install @nirholas/arbitrum-mcp
```

## Available Tools

- `arbitrum_get_network_status` - Network stats for One/Nova
- `arbitrum_estimate_bridge` - Bridge cost estimation
- `arbitrum_get_gas_comparison` - L1 vs L2 gas comparison
- `arbitrum_get_top_dapps` - Popular Arbitrum dApps
