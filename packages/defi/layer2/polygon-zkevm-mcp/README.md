# Polygon zkEVM MCP Server

> Zero-knowledge rollup integration for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 🟣 **Network Status** - Batches, proofs, gas prices
- 🌉 **Bridging** - Fast ZK-verified bridging
- 📦 **Batches** - Proof generation and verification
- 🌐 **Ecosystem** - Polygon network integrations

## Available Tools

- `polygon_zkevm_get_status` - Network and batch status
- `polygon_zkevm_get_bridge` - Bridge information
- `polygon_zkevm_get_batches` - Batch and proof info
- `polygon_zkevm_get_ecosystem` - dApps and ecosystem
