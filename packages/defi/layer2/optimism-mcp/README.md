## Features

- 🔴 **Network Status** - Sequencer, gas prices, block height
- 🌉 **Bridging** - Standard bridge and fast bridge options
- 🪙 **OP Token** - Governance and token info
- ⛓️ **Superchain** - Ecosystem of OP Stack chains

## Available Tools

- `optimism_get_network_status` - Network and sequencer status
- `optimism_get_bridge_info` - Bridge options and timing
- `optimism_get_op_token` - OP token and governance
- `optimism_get_superchain` - Superchain ecosystem info
