# Base Chain MCP Server

> Coinbase L2 integration for AI assistants

**Author:** nirholas (Nich)  
**Website:** [x.com/nichxbt](https://x.com/nichxbt)  
**License:** MIT

## Features

- 🔵 **Network Status** - Gas prices, block height
- 🏦 **Coinbase** - Native Coinbase integrations
- 📱 **dApps** - Popular Base protocols
- 🌉 **Bridging** - Official and fast bridges

## Available Tools

- `base_get_network_status` - Network statistics
- `base_get_coinbase_integrations` - Coinbase features
- `base_get_top_dapps` - Popular dApps
- `base_get_bridge_info` - Bridge options
